# Product Brief: 个人开销统计仪表盘 (Personal Expense Dashboard)

## Executive Summary

个人开销统计仪表盘是一款轻量级纯前端 Web 应用，帮助用户录入、分类和可视化自己的日常消费数据。用户只需在浏览器中打开页面，即可快速添加一笔笔开销记录，系统自动按类别、月份、时间区间生成环形图、柱状图和趋势折线图，让"钱花到了哪里"一目了然。所有数据存储在浏览器本地（localStorage），无需注册、无需联网、零隐私顾虑。

这不是一个功能庞大的财务软件——它解决的是一个具体而常见的小痛点：**我到底把钱花到哪了？** 学生和刚工作的年轻人每月收到工资/生活费后，往往只知道"钱又没了"，却说不清具体流向。本应用用极低的使用门槛（无需登录、打开即用）让消费分析变得可视化、可回看、可对比。

## The Problem

当前年轻人管理个人开销的常见方式：
- **纯靠脑子记**：月初还能大概有数，月底只剩"钱又没了"的模糊印象
- **微信/支付宝账单逐条翻**：平台自带的分类统计粗粒度、不支持自定义类别合并、多个支付渠道数据分散
- **Excel/记事本记账**：太麻烦，难以坚持；统计全靠手动计算
- **下载财务 App**：注册繁琐、担心隐私、功能太重杀鸡用牛刀

核心痛点：
1. **开销流向不透明** —— 不知道自己花了多少钱在外卖、奶茶、娱乐上
2. **跨渠道无法统一** —— 微信、支付宝、现金消费分散，很难形成完整画像
3. **记账门槛高** —— 现有方案要么复杂、要么依赖服务器，用户不愿坚持

## The Solution

一款纯前端、零依赖的单页仪表盘应用，核心体验：

1. **快速录入**：一键添加一笔开销（金额、类别、日期、备注），2 秒完成
2. **即时可视化**：输入后图表自动刷新，按类别展示占比（环形图）、按月份/日期展示趋势（柱状图+折线图）
3. **数据回看**：支持按日期区间筛选、按类别查看明细记录
4. **本地持久化**：所有数据存在浏览器 localStorage，刷新不丢失；支持导出/导入 JSON 备份

不做什么？不做预算提醒、不做账户同步、不做借贷管理——聚焦"录入 → 看到"这条最短路径。

## What Makes This Different

- **零门槛**：打开 HTML 文件即可使用，无需 npm install、无需后端服务、无需注册账号
- **隐私优先**：所有数据 100% 本地存储，不上传任何服务器
- **即时反馈**：每录入一笔开销，图表实时更新，让用户立刻感受到"可视化在帮我理解自己"

坦率地说，这个产品没有技术护城河——它的价值在于**简单到用户愿意每天用**。市面上很多财务应用死在"太复杂"，本项目的竞争力就是做减法。

## Who This Serves

**主要用户：** 大学生和刚毕业的职场新人（18-28 岁）
- 每月有固定收入/生活费，但消费习惯还在养成中
- 对"月光"有焦虑，但不愿为记账花太多精力
- 日常消费高度数字化（外卖、奶茶、网购、游戏），类别集中但分散在多个 App 里

**次要用户：** 对个人财务管理感兴趣、但不想下载 App 的任何人

## Success Criteria

| 维度 | 衡量 |
|------|------|
| 功能完整性 | 核心流程"打开→录入→看到图表"可无阻塞跑通 |
| 数据持久化 | 录入数据关闭浏览器重开后仍然存在 |
| 演示流畅度 | 从启动到展示完整仪表盘，演示时间 < 30 秒 |
| 构建通过 | `npm run build`（或纯 HTML 直接打开）无报错 |

## Scope

### In Scope (V1)
- 开销录入表单（金额、类别、日期、备注）
- 预置常见类别（餐饮、交通、购物、娱乐、居住、其他）+ 支持自定义类别
- 3 种图表：类别占比环形图、月度支出柱状图、支出趋势折线图
- 开销列表（可按日期排序、按类别筛选）
- localStorage 持久化 + JSON 导出/导入备份
- 统计卡片（总支出、本月支出、最高单笔）

### Out of Scope (V1 明确不做)
- 预算设置与提醒
- 收入管理
- 登录/注册/多设备同步
- 移动端 App / 小程序
- 账单拍照 OCR 自动识别
- 多人共享账本

## Vision

如果这个小工具被验证有效，它会演进成**个人财务数据的"本地第一"处理框架**：
1. V2 加入 CSV 导入（从微信/支付宝账单导出）
2. V3 支持简单预算线和超支标记
3. V4 变成可扩展的本地数据面板——用户可以自定义数据源和图表类型

但**当前版本就是一个单文件打开即用的小仪表盘**，价值在于把最简单的事做对。
